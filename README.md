💼 Fiscal Phantom: The Offshore Tycoon

"La cupidité est un péché, mais se faire prendre est un crime."

Fiscal Phantom est un jeu incremental (Idle/Clicker) satirique développé en HTML5. Le but est de bâtir un empire financier douteux, de blanchir de l'argent sale, et surtout d'éviter les audits fiscaux à tout prix.

🎮 Fonctionnalités

Gestion de Risque : Une jauge de "Risque Fiscal" monte à mesure que vous gagnez de l'argent. Si elle atteint 100%, c'est l'audit !

Système d'Investissement : Achetez des bâtiments allant du simple "Stand de limonade" à la "Banque Offshore".

Arbre de Recherche (R&D) : Débloquez des technologies avancées pour améliorer votre blanchiment d'argent.

Compétences Actives : Utilisez des "Campagnes de Désinformation" ou trouvez des "Boucs Émissaires" pour réduire votre risque en urgence.

Événements Aléatoires : "Panama Papers", fuites de données, et journalistes trop curieux viendront pimenter votre partie.

Game Over : Après 5 condamnations majeures, c'est la prison et la fin de partie.

🚀 Installation & Lancement

Ce projet est une application web statique (Single Page Application). Il ne nécessite aucune installation de serveur (Node.js, PHP, etc.).

Option 1 : Lancement Local

Téléchargez le fichier index.html.

Double-cliquez dessus pour l'ouvrir dans votre navigateur web favori (Chrome, Firefox, Edge).

Option 2 : Hébergement sur GitHub Pages

Créez un nouveau dépôt sur GitHub.

Ajoutez le fichier index.html à la racine.

Allez dans les Settings du dépôt -> Pages.

Sélectionnez la branche main (ou master) et sauvegardez.

Votre jeu sera accessible via https://votre-pseudo.github.io/votre-depot/.

🛠️ Structure du code

Le projet est contenu dans un fichier unique pour faciliter le partage et le prototypage rapide, mais il suit une structure modulaire interne :

HTML : Structure du DOM et mise en page.

CSS : Styles, animations et responsive design (Mobile & Desktop).

JS : Logique de jeu, boucles de gameplay et gestion de l'état (GameState).
